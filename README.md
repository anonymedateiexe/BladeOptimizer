# ⚡ BladeSettings

### 🚀 Optimize. Customize. Perform.

**BladeSettings** is a lightweight Windows optimizer designed to help you manage system settings, improve your Windows experience, and keep your PC running smoothly.

Built for gamers and everyday users who want a simple, clean, and easy-to-use optimization tool.

![Status]((https://i.postimg.cc/Wbc0bQdS/Neon-Tech-Banner-Nicht-verfugbar.png))

---

## 🎮 Features

- ⚡ **System Optimization** — Access useful Windows optimization settings in one place.
- 🎯 **Gaming Focused** — Designed with gamers and performance enthusiasts in mind.
- 🧹 **System Cleanup** — Add tools for removing unnecessary temporary files.
- 🛠️ **Windows Tweaks** — Manage selected Windows settings with ease.
- 🖥️ **Simple Interface** — Clean, modern, and easy to navigate.
- 🔒 **User Control** — Choose which optimizations you want to apply.

> Features depend on the current version of BladeSettings. Not every feature may be implemented yet.

## 📥 Installation

1. Open the [Releases] page.
2. Download the latest available Windows release.
3. Extract the downloaded files if necessary.
4. Run `BladeOptimizer.exe`.
5. Apply the optimizations you want to use.

**Note:** If a feature requires administrator privileges, Windows may request permission. Only download releases from sources you trust.

## 🖥️ System Requirements

- **Operating System:** Windows 10 / Windows 11
- **Architecture:** x64 (if supported by the release)
- **RAM:** Depends on the features enabled
- **Permissions:** Administrator privileges may be required for certain system changes
